# SignCraft MVP 수정 내역

## 수정한 이슈

1. QR 디스플레이 화면 최신 반영 개선
- 텍스트/이미지/이모지/사이즈 변경 시 `saveLiveProject()`가 호출되도록 수정했습니다.
- 기존에는 일부 수정 작업이 CMS 목록 저장에는 반영되지만, QR 디스플레이용 live 저장소에는 저장되지 않아 새로고침해도 예전 내용이 보일 수 있었습니다.
- 외부 디스플레이 화면은 2초마다 확인하고, 같은 브라우저 환경에서는 localStorage 변경 이벤트도 감지하도록 보완했습니다.

2. 이미지 표시 개선
- 이미지 업로드 시 큰 이미지는 최대 1600px 기준으로 리사이즈하여 저장하도록 수정했습니다.
- 이미지 데이터가 너무 커서 localStorage 저장이 실패하는 가능성을 낮췄습니다.
- QR 디스플레이가 같은 도메인/같은 브라우저 저장소에서 live 데이터를 읽을 수 있으면 이미지도 함께 표시됩니다.

3. 간판 사이즈 직접 입력 오류 수정
- 가로/세로 cm 입력값이 이전 값으로 되돌아가거나 앞자리 입력이 어려웠던 문제를 수정했습니다.
- 입력 중에는 로컬 입력값으로 관리하고, Enter 또는 blur 시 10~1000cm 범위로 보정하여 반영합니다.

## 중요한 한계

현재 앱은 GitHub Pages/Vercel 정적 프론트엔드 MVP 구조입니다. 따라서 서로 다른 기기 간 CMS 수정 내용이 완전한 실시간으로 동기화되려면 Firebase, Supabase, 서버 API 같은 백엔드 저장소가 필요합니다. 이번 패치는 현재 구조 안에서 누락된 live 저장/새로고침/이미지 저장 문제를 최대한 보완한 것입니다.
